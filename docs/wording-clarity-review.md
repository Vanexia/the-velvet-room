# August-onward wording review

11 October 2026. Reviewed all **235 instructions across 86 dates**, from 1 August through 26 October. Rewrote **122 instructions**. All earlier dated instructions remain unchanged.

## Reading rules

- Today's actions appear in activity order. Free preparation comes before an event that spends time.
- A conditional step says which single activity to choose. Later replacement dates appear separately from today's choice.
- An ongoing goal can span several battles or journeys. Its presence on a date does not create a training deadline.
- A reminder for later does not add another evening activity. Explicit deadlines and prerequisite checks still apply.

The reader's shared guidance and footer now explain these rules. The party panel says “Training advice” and “Requirements for this setup”; its training text distinguishes preparation for a suggested tactic from an upgrade goal. The pre-August party data is unchanged. A new 1 August phase keeps edits to the shared July setup from changing earlier recommendations.
